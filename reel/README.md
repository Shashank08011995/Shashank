# Psychedelic Hi-Tech Ritual – Instagram Reel

| File | What it is |
|---|---|
| `ritual_reel.mp4` | Final reel, 1080×1920, 30 fps, 20.8 s, with music |
| `reel_cover.jpg` | Cover / thumbnail frame for the reel |
| `ritual_track.wav` | The original 150 BPM psytrance track on its own (copyright-free, synthesised) |
| `make_music.py` | Generates the track |
| `make_reel.py` | Renders the video, beat-synced to the track |

## Rebuild
```
python3 make_music.py ritual_track.wav
python3 make_reel.py poster.jpg ritual_track.wav ritual_reel.mp4 fonts
```
